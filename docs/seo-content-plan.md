# コラムのテーマ計画（seo-content-plan）

週次タスクが毎週1本（2026-10-20 オーナー決定。それまでは2週に1本）、ここからテーマを選んでコラムを書く（手順は [SEO_PLAYBOOK.md](SEO_PLAYBOOK.md)「8. コラムの自動作成」、書き方は [column-guide.md](column-guide.md)）。
オーナーが書きたいテーマを足すときは、下の表に1行加えるだけでよい（優先度を「高」にすると先に書く）。

## 選び方

- **目的は、記事から経理代行などのサービスへの問い合わせを増やすこと**（2026-10-20 オーナー決定）。そのため、**依頼を検討している段階の人が検索するテーマ**（選び方・依頼の流れ・自社でやるか外に任せるか・導入支援の頼み方・外注の比べ方）を上に置いている。
- 上から順に、**状態が「未着手」で優先度の高いもの**を選ぶ。
- **COANA TOKYO のサービス内容（`content/solutions/*.json`）に合うものだけ**を選ぶ。各テーマには必ず「つなぐLP」を決め、本文の途中の自然な箇所と末尾の CTA（「〜したい方へ」の節）でそのLPへ導く。LP の流れ・対応範囲・FAQ と食い違うことは書かない。
- **既存の記事と重複しない**こと：下の「既存の記事」と見比べ、同じ悩み・同じ結論になるテーマは書かない（備考の「切り口」を守るか、別のテーマにする）。
- 法制度・補助金・税・相場など、**一次情報で確認できないと書けないテーマ**は、確認できたときだけ書く。確認できなければ次のテーマへ。**数字・料金・実績は根拠があるものだけ**（料金は「個別にお見積もり」。サイトにない料金・削減時間・件数は書かない）。
- 士業（税理士・社労士など）の独占業務に当たる判断はしない。役割分担を説明するテーマでも、COANA TOKYO は記帳・資料の準備などの実務と仕組みづくりを担い、専門家と連携・紹介する立場として書く。
- 毎週の振り返りで、この表の並び順と不足を見直す（検討段階のテーマが少なくなったら足す）。書いたら「状態」と「記録」を更新する（PR の中で）。

## 読者（共通）

従業員0〜20名の中小企業の経営者・個人事業主。経理・バックオフィス・集客を本業のかたわら自分でこなしている。スマホで流し読みする（詳しくは column-guide.md「1. 読者像」）。
