# コラムのテーマ計画（seo-content-plan）

週次タスクが2週に1本、ここからテーマを選んでコラムを書く（手順は [SEO_PLAYBOOK.md](SEO_PLAYBOOK.md)「8. コラムの自動作成」、書き方は [column-guide.md](column-guide.md)）。
オーナーが書きたいテーマを足すときは、下の表に1行加えるだけでよい（優先度を「高」にすると先に書く）。

## 選び方

- 上から順に、**状態が「未着手」で優先度の高いもの**を選ぶ。
- **既存の記事と重複しない**こと：下の「既存の記事」と見比べ、同じ悩み・同じ結論になるテーマは書かない（切り口を変えるか、別のテーマにする）。
- 法制度・補助金・税・相場など、**一次情報で確認できないと書けないテーマ**は、確認できたときだけ書く。確認できなければ次のテーマへ。
- 書いたら「状態」と「記録」を更新する（PR の中で）。

## 読者（共通）

従業員0〜20名の中小企業の経営者・個人事業主。経理・バックオフィス・集客を本業のかたわら自分でこなしている。スマホで流し読みする（詳しくは column-guide.md「1. 読者像」）。
