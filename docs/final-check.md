# 公開前の最終チェック

大きな変更のあとは、本番と同じビルド（`npm run build` → `vite preview`、チャットは `wrangler pages dev dist`）で、次をすべて確認する。個別の PR で確認済みでも省略しない。

## 表示
- 全ページ × 9種の幅（320・375・390・414・768・1024・1280・1440・1920px）：横のはみ出し・要素の重なり・画像の読み込み・不自然な改行
- コンソールエラー、リンク切れ、文字と背景のコントラスト（WCAG AA）

## 演出（docs/motion-rules.md）
- 「動きを減らす」設定：すべて最初から表示・静止
- **各ページへの入り方を変えても演出が同じか**：再読み込み、ロゴ、メニュー、ブラウザの戻る・進む、他ページのリンク、#付きで途中に入る。トップの鳩 → 下線 → 回転ワードの順番、各LPの下線・イラスト・HOW IT WORKS
- 同じページ内のスクロールでは、表示済みの演出を繰り返さない

## 操作
- キーボード：Tab で全部の操作に届く・フォーカスが見える
- **全開閉UIの「開く → 閉じる → もう一度開く」**：クリック・タップ・Enter・Space、aria-expanded（FAQ、業務の一覧、HOW IT WORKS の工程の説明、メニュー、チャット）。PC はカーソル・フォーカスで出る説明が、外したあとに出たままにならないこと
- チャット：開閉、選択式、診断の全ルート、AI 応答と代替応答、フォームへの引き継ぎ、スマホのキーボード表示時
- お問い合わせフォーム：スパム対策の欄が見えない・入力 → 確認画面（実際の送信はしない）

## 出力
- SEO（タイトル・説明文・正規URL・構造化データ・sitemap・feed・llms.txt）、旧URLの転送、表示速度（Lighthouse）
